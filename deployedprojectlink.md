## 🔢 Fraction Calculator

The Fraction Calculator is a Python-based application developed using Object-Oriented Programming (OOP), custom data types, operator overloading, and Streamlit.

The application supports fraction arithmetic, automatic simplification, comparison, decimal conversion, and calculation history.

### 🌐 Live Application

👉 [Open Fraction Calculator](https://fraction-calculator-python-njodbeq5iehafawdybcomb.streamlit.app/)

### 🛠️ Deployment Platform

- **Platform:** Streamlit Community Cloud
- **Application Type:** Interactive Web Application
- **Technology:** Python + Streamlit

### 📌 Purpose

This deployment allows users to access and test the Fraction Calculator directly through a web browser without setting up the project locally.
